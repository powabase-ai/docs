This guide covers the basics: your project URL, authentication headers, and a quick verification request. Once you're set up, you can start building with any part of the API.

<Steps>

<Step title="Your Project URL">

Every project has a unique base URL. All API endpoints are relative to this URL.

**Endpoint:** `Base URL`

<CodeGroup>

```python Python
BASE_URL = "{BASE_URL}"
```

```typescript TypeScript
const BASE_URL = "{BASE_URL}";
```

```bash cURL
# Base URL
{BASE_URL}
```

</CodeGroup>

</Step>

<Step title="Authentication">

Include your service_role key in every request. This key has full access and bypasses Row Level Security — never expose it in client-side code.

**Endpoint:** `Headers: apikey + Authorization`

<CodeGroup>

```python Python
import requests

API_KEY = "{API_KEY}"

headers = {
    "apikey": API_KEY,
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json",
}
```

```typescript TypeScript
const API_KEY = "{API_KEY}";

const headers = {
  apikey: API_KEY,
  Authorization: `Bearer ${API_KEY}`,
  "Content-Type": "application/json",
};
```

```bash cURL
# Include in every request:
-H "apikey: {API_KEY}" \
-H "Authorization: Bearer {API_KEY}" \
-H "Content-Type: application/json"
```

</CodeGroup>

</Step>

<Step title="Verify Your Setup">

Make a quick request to list agents. If you get an empty array or a list of agents, your setup is working.

**Endpoint:** `GET /api/agents`

<CodeGroup>

```python Python
response = requests.get(
    f"{BASE_URL}/api/agents",
    headers=headers,
)
print(response.json())
```

```typescript TypeScript
const response = await fetch(`${BASE_URL}/api/agents`, { headers });
const agents = await response.json();
console.log(agents);
```

```bash cURL
curl '{BASE_URL}/api/agents' \
  -H "apikey: {API_KEY}" \
  -H "Authorization: Bearer {API_KEY}"
```

</CodeGroup>

**Response:**

```json
[
  {
    "id": "uuid-here",
    "name": "My Agent",
    "model": "gpt-4o",
    "created_at": "2026-01-01T00:00:00Z"
  }
]
```

</Step>

</Steps>
